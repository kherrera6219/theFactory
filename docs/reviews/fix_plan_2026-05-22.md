## M-03 — Add `make check-env`

**Validated finding:** No `check-env` target in Makefile. `make up` prereq is
`tls-certs` only.

**Add to Makefile:**
```makefile
check-env:
	@if [ ! -f .env ]; then \
		echo "ERROR: .env not found. Run: cp .env.example .env"; exit 1; \
	fi
	@BAD=$$(grep -c "CHANGE_ME" .env 2>/dev/null || echo 0); \
	if [ "$$BAD" -gt 0 ]; then \
		echo "ERROR: $$BAD CHANGE_ME value(s) still in .env:"; \
		grep "CHANGE_ME" .env | head -10; exit 1; \
	fi
	@echo "OK: .env configured"

up: tls-certs check-env
```

**Effort:** 20 minutes

## M-02 — Bound async thread pool executor

**Validated finding:** Lifespan at `main.py:688` has no executor setup. 39
`asyncio.to_thread` calls use unbounded default pool.

**Add to `orchestrator/main.py`:**
```python
# Top of file
from concurrent.futures import ThreadPoolExecutor

# Inside lifespan, before yield
loop = asyncio.get_event_loop()
_executor = ThreadPoolExecutor(
    max_workers=int(os.getenv("ORCHESTRATOR_THREAD_POOL_SIZE", "20")),
    thread_name_prefix="orch-storage",
)
loop.set_default_executor(_executor)

# Inside lifespan, after yield (cleanup)
_executor.shutdown(wait=False)
```

Add to `.env.example`: `ORCHESTRATOR_THREAD_POOL_SIZE=20`
