# Code of Conduct

Document version: 2026.04.14  
Last updated: 2026-04-14  
Status: Canonical

## Our Commitment

We want `theFactory` to be a professional, respectful collaboration space for maintainers, operators, security reviewers, and contributors.

Participants in this project are expected to:

- communicate clearly and respectfully
- assume good intent while still challenging weak technical arguments
- focus critique on code, design, evidence, and decisions rather than people
- protect security, privacy, and operational integrity when sharing examples or logs
- accept feedback and course-correct when behavior creates friction or risk

## Expected Behavior

Examples of behavior that contributes to a healthy project environment:

- using professional language in issues, pull requests, reviews, and chat
- providing evidence for technical claims
- documenting risks, assumptions, and rollback plans when proposing changes
- reporting security concerns through the documented security process instead of public disclosure
- helping new contributors understand local setup, testing expectations, and operational constraints

## Unacceptable Behavior

Examples of unacceptable behavior include:

- harassment, threats, discrimination, or demeaning language
- personal attacks, insults, or repeated bad-faith argumentation
- publishing private information, credentials, tokens, or internal customer data
- intentionally bypassing project controls, security requirements, or review gates
- disruptive spam, trolling, or repeated off-topic discussion that blocks project work

## Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing this code of conduct. They may remove, edit, or reject comments, commits, code, issues, and other contributions that violate these standards.

## Scope

This code of conduct applies within all project spaces, including:

- the Git repository
- issue trackers
- pull requests and code reviews
- release and incident discussions
- project chat or coordination channels used for theFactory work

## Reporting

For conduct issues, contact the repository maintainers through the same private path used for security-sensitive concerns, or use the escalation path documented in [SECURITY.md](SECURITY.md) when the issue intersects with safety, privacy, or operational risk.

## Enforcement Guidelines

Maintainers may apply any action they judge appropriate, including:

- private warning
- temporary restriction from discussions or reviews
- removal of content
- suspension from contribution
- permanent ban from the project space
